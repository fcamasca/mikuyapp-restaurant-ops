# E1 — Notas de entrega

**Fecha:** 21/09/2026  
**Estado:** APROBADA Y CERRADA

## Qué se entregó

- Sesiones de caja con apertura, recuperación, movimientos y cierre revisado.
- Cobros totales o parciales, varios medios y propinas separadas.
- Precuenta, recibo parcial, ticket final y reporte de cierre imprimibles.
- Gestión administrativa de descuentos y pedidos anulables.
- Notificaciones de apertura, cierre y diferencias.
- Inicio ADMIN con indicadores del día, atención pendiente, flujo actual de pedidos, ventas por medio y estado de caja.
- Navegación administrativa responsive.

## Impacto para los usuarios

Caja trabaja con saldos, importes y acciones más claros. Administración obtiene una vista diaria del local, recibe alertas relevantes y puede resolver descuentos o anulaciones permitidas desde accesos visibles.

## Alcance cubierto

La entrega cubre la operación del local actual, el control interno de caja, los documentos internos no fiscales y la supervisión administrativa prevista para E1. TP62, TP63 y TP64 quedaron aprobadas humanamente.

## Exclusiones

No incluye facturación electrónica, SUNAT, conciliación bancaria, operación offline, consolidación multilocal, cancelación individual de productos ni analítica histórica avanzada.
